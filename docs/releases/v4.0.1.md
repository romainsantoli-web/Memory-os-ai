`memory-os-ai`, LGPL-3.0-or-later, Python ≥ 3.11 ; deux moteurs et deux licences.

conservatrices de faits, écrivain unique, reçus JSONL, douze réparations A2,

sur magasins neufs. JSONL/reçus ne forment pas une transaction commune : les
promesses industrielles SQLite attendent S2–S5.

## Qualification des artefacts et publication

Construire wheel **depuis le sdist**, installer chaque artefact hors dépôt dans un
environnement distinct, vérifier licences/notices/provenance/cinq commandes,
`pip check`, `twine check --strict`, lint et suites v3/v4. Le smoke hash vérifie le
contrat/démarrage ; le test MiniLM déjà en cache vérifie une recherche sémantique.
Aucun téléchargement de modèle n'est requis pour le relais synthétique.

`scripts/installed_relay_e2e.py` exécute hors sandbox les deux installations :
imports depuis le site-packages local, origine SHA-256, serveur synthétique hash,
HTTP authentifié et `/ready` avec version/commit attendus, round-trip MCP, SIGKILL,
appel refusé sans rejeu, redémarrage, même session du relais fonctionnelle,
exactement les deux faits acquittés dans la source et arrêt propre. Cette preuve
est une panne de processus, pas une qualification de coupure électrique.

Le rapport porte commit, empreintes des deux artefacts et scripts, résultats des
cas. `verify_release_manifest.py --record-relay-proof` n'ouvre la garde qu'avec
preuves locales complètes et rapport concordant ; un cas absent/échoué, un ancien
artefact ou une preuve modifiée sont refusés. Le script ne publie rien. Romain
exécute ensuite la commande twine du dossier sur les **mêmes** fichiers, sans
reconstruction et sans secret dans la commande. Le GO PyPI n'autorise ni A2 live
ni une bascule SQLite ; leurs décisions opérationnelles restent distinctes.
